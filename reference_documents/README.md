# RHU Centralized Document Binders — Official Reference Specifications

This directory serves as the official reference storage for sample document templates, structured JSON schemas, and OCR classification rules across the **4 RHU Centralized Record Binders**.

---

## 📁 Reference Folder Structure

### 1. `1_Individual_Treatment_Record/`
- **Category Key**: `PATIENT_INFORMATION_SHEET` (Individual Treatment Record)
- **Document Description**: Paete RHU Primary Patient Record (Page 1: Demographics, Lifestyle & Risk Factors, Vital Signs, Initial Clinical Findings; Page 2: Follow-up Consultations).
- **Files**:
  - `ITR_Page1_Paete_RHU_Template.txt` — Full text template for ITR Page 1.
  - `ITR_Page1_Sample_Data.json` — Structured JSON schema for ITR Page 1.
  - `ITR_Page2_Sample_Data.json` — Structured schema for ITR Page 2 (Follow-up Consultations).

---

### 2. `2_Consultation_Records/`
- **Category Key**: `CONSULTATION_RECORD`
- **Document Description**: Doctor consultation sheets, progress notes, laboratory/x-ray results, and prescription notes.
- **Files**:
  - `Consultation_Record_Sample.txt` — Consultation notes reference format.

---

### 3. `3_Immunizations/`
- **Category Key**: `IMMUNIZATION_RECORD`
- **Document Description**: Routine childhood immunization records, baby books, BCG, DPT, OPV, IPV, Measles/MMR vaccination cards.
- **Files**:
  - `Immunization_Record_Sample.txt` — Immunization log reference format.

---

### 4. `4_Maternal_Care/`
- **Category Key**: `MATERNAL_CARE_RECORD`
- **Document Description**: Prenatal checkup logs, OB-GYN records, fetal ultrasound reports, tetanus toxoid logs, and postpartum care.
- **Files**:
  - `Maternal_Care_Record_Sample.txt` — Maternal care log reference format.
